# Project instructions

Read `CODEX.md` for project context before making changes.

## Commit, tag, and push

After completing requested changes and the relevant verification:

1. Commit the task's changes with a descriptive message.
2. Create an annotated tag on that commit using `vYY.MM.DD.HH.mm`, with the
   current date and time in `Europe/Stockholm` (for example, `v26.10.03.19.30`).
   Use `Broker Explorer <tag>` as the tag message.
3. Push the commit and that specific tag to `origin`.

This workflow is authorized by the user. Follow any later user instruction to
skip or delay committing or pushing. Do not include unrelated user changes.
Never overwrite an existing tag; if the minute is already used, wait until the
next minute before creating the new tag. Report the commit and tag when done.
